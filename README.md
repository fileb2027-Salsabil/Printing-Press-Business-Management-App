# মক্কা প্রিন্টার্স (Makkah Printers) - Business Management & Accounting App

মক্কা প্রিন্টার্সের সম্পূর্ণ হিসাব, দৈনিক প্রডাকশন, কাস্টমার খাতা, বিল ও ইনভয়েস, কালেকশন, কর্মচারী ব্যবস্থাপনা, দৈনিক হাজিরা, বেতন ও ওভারটাইম (৭০%), কাগজ কাটিং, পট্টি বিক্রি এবং মাল্টি-পিরিয়ড রিপোর্ট পরিচালনার জন্য একটি আধুনিক ও পূর্ণাঙ্গ বিজনেস ম্যানেজমেন্ট সফটওয়্যার।

---

## বৈশিষ্ট্যসমূহ (Key Features)

১. **প্রাথমিক সেটআপ উইজার্ড (First-Time Setup Wizard)**
   - প্রতিষ্ঠানের নাম, ঠিকানা ও লোগো আপলোড
   - মালিক ও পরিচালকের ছবি ও মোবাইল নম্বর
   - প্রারম্ভিক হিসাব শুরুর তারিখ ও ওপেনিং ব্যালেন্স
   - ডিফল্ট ভাষা ও বাংলা ফন্ট নির্বাচন (Hind Siliguri, Noto Sans Bengali, Tiro Bangla)
   - কালার থিম নির্বাচন (পান্না সবুজ, মহাসাগর নীল, রক্তিম মেরুন, আধুনিক ধূসর, ডার্ক মোড)
   - সিকিউরিটি পিন ও ব্যবসায়িক নীতি

২. **ড্যাশবোর্ড (Live Dashboard)**
   - আজকের মোট প্রডাকশন (রিম ও ফর্মা)
   - আজকের মোট কালেকশন ও জমা
   - আজকের আয় ও ব্যয়
   - আজকের কাগজ কাটিং খরচ
   - আজকের পট্টি বিক্রি (কেজি ও টাকা)
   - কর্মচারীদের উপস্থিতি/অনুপস্থিতি কাউন্টার
   - চলতি মাসের নিট লাভ/ক্ষতি
   - কাস্টমারদের মোট বকেয়া ও কর্মচারীদের মোট অগ্রিম

৩. **কাস্টমার / পার্টি ব্যবস্থাপনা (Customer / Party Management)**
   - ৯টি ট্যাববিশিষ্ট বিস্তারিত পার্টি প্রোফাইল
   - স্বয়ংক্রিয় পার্টি খাতা ও ডেবিট-ক্রেডিট লেজার
   - বকেয়া হিসাব ও প্রিন্টযোগ্য স্টেটমেন্ট

৪. **বই ব্যবস্থাপনা (Book Catalog)**
   - গ্লোবাল বইয়ের তালিকা, কোড, ফর্মা, প্লেট সংখ্যা ও ডিফল্ট রেট
   - একাধিক পার্টির সাথে বই সংযুক্তিকরণ

৫. **দৈনিক প্রডাকশন (Daily Production)**
   - অফসেট ছাপা, ফর্মা, প্লেট, কপি, শিট ও রিম হিসাব
   - বিল করা হয়েছে কি না (Billed/Unbilled) ট্র্যাকিং

৬. **বিল ও ইনভয়েস (Billing & Invoicing)**
   - বকেয়া প্রডাকশন থেকে চেকআউট করে আইটেমাইজড বিল তৈরি
   - বই, পার্টি বা গ্লোবাল রেট প্রয়োগ
   - ছাড়, অতিরিক্ত চার্জ ও নগদ জমার হিসাব
   - প্রিন্ট-রেডি ইনভয়েস ভাউচার ও সিগনেচার লাইন

৭. **দৈনিক কালেকশন (Daily Collections)**
   - নগদ, ব্যাংক বা মোবাইল ব্যাংকিং জমা রসিদ
   - মানি রসিদ (Money Receipt) প্রিন্ট

৮. **কর্মচারী, হাজিরা ও বেতন নীতি (Attendance, Bonus & Payroll)**
   - ক্যালেন্ডার অনুযায়ী সঠিক দিনসংখ্যা ($M$) নির্ধারণ (ফেব্রুয়ারি ২৮/২৯ লিপ ইয়ার)
   - অনুপস্থিতির জন্য দৈনিক বেতন কাটা ($D \times R$)
   - **বাধ্যতামূলক বোনাস নীতি**: মাসে ঠিক ২৩ দিন অথবা পূর্ণ মাস উপস্থিত থাকলে ২ দিনের মূল বেতন বোনাস
   - **ওভারটাইম নীতি**: মাসিক নির্ধারিত স্বাভাবিক কর্মঘণ্টার (২০৮ ঘণ্টা) ভিত্তিতে মূল বেতনের ৭০% হারে OT গণনা
   - অগ্রিম রেজিস্টার এবং বেতন থেকে স্বয়ংক্রিয় কর্তন
   - একক পে-স্লিপ ও সম্মিলিত হাজিরা ও OT শিট

৯. **কাগজ কাটিং ব্যবস্থাপনা (Paper Cutting)**
   - কাটিং ম্যান তালিকা ও প্রতি রিমের দর
   - কাটিং খরচ স্বয়ংক্রিয়ভাবে কোম্পানির ব্যয়ের খাতায় সংযোজন

১০. **পট্টি বিক্রির হিসাব (Putti / Scrap Sales)**
    - ৭টি নির্দিষ্ট ক্যাটাগরি (সাদা, সাদা-২, নিউজ, নিউজ-২, খাস্তা, মলাট, ২নং)
    - মোট বিক্রি, অগ্রিম গ্রহণ ও অবশিষ্ট বকেয়া

১১. **ডেটা ম্যানেজমেন্ট ও সিকিউরিটি**
    - ১-ক্লিকে সম্পূর্ণ JSON ব্যাকআপ ডাউনলোড
    - JSON ব্যাকআপ রিস্টোর
    - অ্যাডমিন পিন ভেরিফিকেশনে "নতুন করে হিসাব শুরু" (রিসেট) সুবিধা

১২. **ইন-অ্যাপ অটোমেটেড টেস্ট রানার (Automated Tests Suite)**
    - ২০টি নির্ধারিত গাণিতিক ও অ্যাকাউন্টিং নিয়মের টেস্ট স্যুট

## রান করার নিয়ম (How to Run Locally)

```bash
# ১. ডিপেনডেন্সি ইন্সটল
npm install

# ২. ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# ৩. প্রোডাকশন বিল্ড তৈরি
npm run build
```

## টেকনোলজি স্ট্যাক (Technology Stack)

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Data Persistence**: Offline-first LocalStorage & IndexedDB with JSON Backup/Restore
- **Cloud Database (Optional)**: Firebase Cloud Firestore & Firebase Auth compatible (`firestore.rules` included)

## GitHub ও Vercel-এ লাইভ করার নিয়ম (Deploy via GitHub & Vercel)

১. প্রজেক্টটি **GitHub Repository**-তে পুশ করুন।
২. [Vercel](https://vercel.com)-এ লগইন করে **Add New → Project** থেকে আপনার GitHub রিপোজিটরি সিলেক্ট করুন।
৩. প্রজেক্টে `vercel.json` আগে থেকেই সেট করা আছে (`Framework: Vite`, `Build Command: npm run build`, `Output Directory: dist`)—কোনো অতিরিক্ত এনভায়রনমেন্ট ভেরিয়েবল ছাড়াই **Deploy** ক্লিক করুন।
৪. **Google Login (ঐচ্ছিক)**: ইমেইল/ইউজারনেম ও পাসওয়ার্ড লগইন এবং পার্টি পোর্টাল সাথে সাথেই কাজ করবে। Google Sign-In বাটন চালু করতে Firebase Console → **Authentication → Settings → Authorized domains**-এ আপনার `your-project.vercel.app` ডোমেইনটি যোগ করে দিন।
